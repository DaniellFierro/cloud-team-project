# Архитектура Cloud Service Catalog

Приложение является небольшим монолитом: один процесс Python обрабатывает HTTP-запросы
и читает локальный JSON-каталог. Отдельных микросервисов и базы данных нет.

Клиент → HTTP Handler → services.json → JSON-ответ клиенту.
Для главной страницы обработчик формирует HTML, а /health возвращает состояние процесса.

| Компонент | Ответственность |
|---|---|
| Браузер или curl | Отправляет HTTP GET и получает HTML/JSON |
| app/main.py | Маршрутизация запросов и формирование ответов |
| app/services.json | Неизменяемый во время работы каталог IaaS/PaaS/SaaS |
| Переменные окружения | Адрес, порт и заголовок приложения |

Этот сервер предназначен для учебных проверок в контролируемой среде.

## Настройка окружения

config/example.env — образец APP_TITLE, HOST и PORT. Приложение не загружает .env автоматически; переменные экспортируются оболочкой до запуска. HOST задаёт интерфейс, PORT — порт, APP_TITLE — заголовок HTML. Реальные секреты хранятся вне Git.
