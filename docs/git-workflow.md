# Порядок разработки

Автор и единственный участник: Сазонов Даниил Евгеньевич, DaniellFierro.

1. Создать Issue с проверяемым результатом и назначить исполнителя.
2. От актуальной main создать feature/<краткое-имя>.
3. Сделать изменения, выполнить тесты и git diff --check.
4. Выполнить commit и push, создать Pull Request с Closes #номер.
5. Проверить diff и результаты тестов, исправить замечания отдельным коммитом.
6. Объединить PR и убедиться, что связанная задача закрыта.

В проекте предусмотрены шаблоны задач, PR и порядок проверки тестами.
При расширении команды владелец приглашает реальные аккаунты через Settings → Collaborators.
Сейчас других участников нет. Самопроверка автора не является независимым review;
GitHub не позволяет автору одобрить собственный PR. Пароли и токены не передаются.
