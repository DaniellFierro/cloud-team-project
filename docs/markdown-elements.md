# Элементы Markdown в README

| Элемент | Применение |
|---|---|
| Заголовки `#`, `##` | Название и разделы |
| Маркированный список | Возможности |
| Нумерованный список | Шаги Linux-запуска |
| Таблицы | Архитектура, параметры и маршруты |
| Ссылки | Документация и Issues |
| Полужирное выделение | Модели и автор |
| Встроенный код | Имена файлов, параметры |
| Блоки bash, powershell, text | Исполняемые команды и структура |
