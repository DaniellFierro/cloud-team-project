# Формат каталога

Корневой JSON-объект содержит массив `services`. У каждой записи есть строковые поля
`model`, `example`, `description`. Три значения model: IaaS, PaaS, SaaS.

| Модель | Что предоставляет | Ответственность пользователя |
|---|---|---|
| IaaS | Вычисления, сеть, диски | ОС, зависимости и приложение |
| PaaS | Среду размещения приложения | Код и данные приложения |
| SaaS | Готовое приложение | Использование и настройка доступа |

`example` содержит типовой класс сервиса, а не заявление о реально созданном платном ресурсе.
Изменение файла проходит через Git. API доступен только для чтения.
